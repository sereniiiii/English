# 必刷题库 · 高中必刷题（英语 · 人教版 2026）

把扫描版《高中必刷题》拆成可直接刷的题库：左列题目、右列答案，可收藏、可批注、可改题、可回看原书扫描页。

## 打开方式

- 线上：Vercel 部署后直接访问域名
- 本地：双击 `index.html`（纯静态，无需服务器、不联网）

## 收录

| 册 | 主书 | 配套 |
|---|---|---|
| 英语 必修 第三册 | 97 页 | 快速对答案 3 页 · 狂K重点 58 页 |
| 英语 选修 第三、四册 | 153 页 | 快速对答案 3 页 · 狂K重点 97 页 |
| 英语 必修 第一、二册（合订） | 169 页 | 无答案文件 |
| 英语 选修 第一、二册（合订） | 156 页 | 答案及解析 84 页 |

`data/books.js` 是全部题目文本，`data/pages/` 是扫描原页（WebP）。

## 功能

- **按书 / 单元 / 课时 / 板块**定位，目录显示每块题量
- **左右对照**：题目在左，答案在右，题号对齐；点选项即可记录作答，对错自动标色
- **收藏夹**：记下「哪本书 · 哪一章 · 什么时候」收藏的，可按掌握度筛选
- **批注**：写笔记 + 标「会了 / 模糊 / 不会」，不动原题文字，复习时按掌握度过滤
- **改题**：OCR 识别错的地方可直接改，只存本地，可一键还原
- **原文对照**：每道题都能翻到扫描原页并高亮位置；有答案册的可直接跳答案页
- **全文搜索**：题干、选项、原文一起搜
- **数据备份**：收藏/批注/作答可导出 JSON，换设备可导入

## 已知限制

- 题目文字由 macOS Vision 本地 OCR 生成。英文正文准确度高，中文小标题和个别数字会有识别错误（如「填人」应为「填入」），以「原文」为准。
- 答案覆盖：客观题（阅读 / 七选五 / 完形）基本齐全；单句填空、单句表达、语法填空、写作类答案在配套《答案及解析》册里，本套文件只含「快速对答案」的客观题字母，因此这些题型显示「未匹配答案」。
- 综合测试卷的答案册按 1–70 连续编号，与按篇切分的题卡未做自动对齐，请用「原文」翻答案页。
